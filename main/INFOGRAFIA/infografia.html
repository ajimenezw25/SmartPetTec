SmartPetHome — resumen del proyecto

Universidad · 2026 · prototipo de monitoreo y cuidado de mascotas

Lo que se logró

Conclusiones

  • Sistema funcional de extremo a extremo: ESP32 → MQTT → Flask → Supabase → UI
  • Comunicación en tiempo real entre hardware y app web
  • Registro y visualización de telemetría de dispositivos
  • Autenticación de usuarios y gestión de mascotas
  • Ejecutable de escritorio con PyInstaller
  • Primer dispositivo físico probado: alimentador automático
Lo que aprendimos

Aprendizajes

  • Integrar hardware (ESP32) con software en la nube no es trivial
  • MQTT es ideal para IoT: ligero y asíncrono
  • Supabase acelera el backend con DB + auth listos
  • PyInstaller tiene sus propios trucos de compatibilidad
  • El broker público de EMQX funciona bien para prototipos
  • Iterar rápido en hardware requiere buen debug serial
Para el futuro

Qué mejorar
